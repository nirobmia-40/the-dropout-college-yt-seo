# 🎬 The Dropout College — YouTube SEO Expert Skill

An **Antigravity AI custom skill** that transforms the AI agent into a YouTube SEO Expert. Just provide your video topic and get a complete SEO-optimized package — titles, descriptions, tags, hashtags, thumbnail text, and SEO scorecard.

## ✨ Features

| Feature | Description |
|---|---|
| 🔍 **Keyword Research** | Primary, secondary, long-tail, and LSI keyword analysis with scoring |
| ✍️ **Title Generation** | 5-10 SEO-optimized title options with individual scores |
| 📝 **Description Writing** | Full 5000-char optimized description with hooks, timestamps, CTAs |
| 🏷️ **Smart Tags** | 30-50 categorized tags within YouTube's 500-char limit |
| #️⃣ **Hashtag Strategy** | 3-5 strategic hashtags (broad + niche + trending mix) |
| 🖼️ **Thumbnail Text** | CTR-boosting thumbnail text suggestions with color recommendations |
| 📈 **SEO Scorecard** | 0-100 score with category breakdown (title, description, tags, etc.) |
| 🔎 **Competitor Analysis** | Content gap identification and unique angle suggestions |
| 🌐 **Bilingual Support** | Full support for Bangla, English, and Mixed content |

## 🚀 Installation

### For Antigravity AI Users

Copy the skill folder to your global config:

```bash
cp -r yt-seo-expert/ ~/.gemini/config/skills/yt-seo-expert/
```

The skill will be automatically discovered and available in all conversations.

### Standalone Script Usage

You can also use the Python scripts independently:

```bash
# Keyword Analysis
python3 scripts/keyword_analyzer.py "Your Video Topic" "english"

# SEO Score Check
python3 scripts/seo_scorer.py --type title "Your Title Here" "primary keyword"

# Tag Generation
python3 scripts/tag_generator.py "Your Topic" "primary keyword" "english"
```
