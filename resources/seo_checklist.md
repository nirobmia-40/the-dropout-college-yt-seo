# ✅ YouTube SEO Checklist

ভিডিও পাবলিশ করার আগে এই চেকলিস্ট ফলো করো:

---

## 📌 Title Checklist
- [ ] Primary keyword আছে title-এ
- [ ] Keyword title-এর প্রথম ৪০ characters-এর মধ্যে
- [ ] Title length ৬০-৭০ characters
- [ ] Power word আছে (Best, Ultimate, How to, etc.)
- [ ] Number বা Year আছে
- [ ] Title পড়লে click করতে ইচ্ছা করে (CTR-friendly)
- [ ] ALL CAPS ব্যবহার করা হয়নি (শুধু ১-২ word capitalize ঠিক আছে)
- [ ] Clickbait নয়, কিন্তু curiosity তৈরি করে

## 📌 Description Checklist
- [ ] প্রথম ২-৩ লাইন hook-ই primary keyword আছে
- [ ] Description ১০০০+ characters
- [ ] Keyword density ১-৩%
- [ ] Timestamps/chapters যোগ করা হয়েছে
- [ ] CTA আছে (Subscribe, Like, Comment)
- [ ] Social media links আছে
- [ ] ৩-৫টা hashtags আছে description-এর শেষে
- [ ] Links প্রথম paragraph-এর পরে আছে (আগে নয়)
- [ ] কোনো broken link নেই
- [ ] Spam-y লাগছে না, natural পড়া যাচ্ছে

## 📌 Tags Checklist
- [ ] Primary keyword first tag হিসেবে আছে
- [ ] ২০-৪০টা tags আছে
- [ ] Total characters ৫০০-এর মধ্যে
- [ ] Short tags + Long-tail tags মিক্স আছে
- [ ] Irrelevant tags নেই (YouTube penalty দিতে পারে)
- [ ] Competitor-related tags আছে
- [ ] Bangla transliteration tags আছে (যদি Bangla content হয়)

## 📌 Hashtags Checklist
- [ ] ৩-৫টা hashtags (১৫-এর বেশি নয়)
- [ ] ১টা broad hashtag (বেশি reach-এর জন্য)
- [ ] ১-২টা niche hashtag
- [ ] Description-এর শেষে বা প্রথমে আছে
- [ ] Hashtags relevant এবং trending

## 📌 Thumbnail Checklist
- [ ] Text ৪-৬ words-এর মধ্যে
- [ ] Mobile-এ readable (ছোট screen-এ দেখা যায়)
- [ ] High contrast colors ব্যবহার করা হয়েছে
- [ ] Face/expression আছে (CTR বাড়ায়)
- [ ] Title-এর exact copy নয় (complement করে)
- [ ] Clutter-free, clean design

## 📌 Upload Settings Checklist
- [ ] Correct category select করা হয়েছে
- [ ] Proper language set করা হয়েছে
- [ ] End screen যোগ করা হয়েছে
- [ ] Cards যোগ করা হয়েছে (related videos-এ)
- [ ] Playlist-এ add করা হয়েছে
- [ ] Custom thumbnail upload করা হয়েছে
- [ ] Subtitles/CC যোগ করা হয়েছে (বা auto-generated check করা হয়েছে)

---

> 💡 **Pro Tip**: প্রতিটা ভিডিওর জন্য এই চেকলিস্ট follow করলে ধীরে ধীরে SEO habit হয়ে যাবে!
