# 📚 YouTube SEO Best Practices Guide

## 🔍 YouTube Search কিভাবে কাজ করে

YouTube search তিনটি মূল factor দিয়ে rank করে:
1. **Relevance** — ভিডিওর content কতটা query-র সাথে match করে
2. **Engagement** — Watch time, likes, comments, shares
3. **Quality** — Channel authority, consistency, production value

---

## 📋 Title Best Practices

### Do's ✅
- Primary keyword সামনে রাখো (প্রথম ৪০ characters)
- ৬০-৭০ characters-এর মধ্যে রাখো
- Power words ব্যবহার করো (Ultimate, Complete, Best, Secret)
- Numbers ব্যবহার করো ("5 Tips", "Top 10", "3 Mistakes")
- Year যোগ করো freshness-এর জন্য ("2026")
- Pipe `|` বা dash `—` দিয়ে separate করো
- Curiosity gap তৈরি করো

### Don'ts ❌
- ALL CAPS করো না (YouTube spam মনে করে)
- Clickbait করো না (watch time কমে যাবে)
- Keyword stuff করো না
- খুব generic title দিও না
- ৮০+ characters করো না (truncate হয়ে যায়)

### Title Formulas 💡
```
[Number] + [Adjective] + [Keyword] + [Promise] + [Year]
→ "7 Essential Python Tips That Will Make You a Pro Developer (2026)"

How to + [Keyword] + [Benefit]
→ "How to Build AI Agent with Python — Complete Guide for Beginners"

[Keyword]: [Surprising Fact/Statement]
→ "Machine Learning: You've Been Doing It Wrong This Whole Time"

[Keyword] vs [Alternative] — [Verdict]
→ "React vs Next.js — Which Should You Learn in 2026?"
```

## 📝 Description Best Practices

### First 150 Characters (CRITICAL)
- এটাই search results-এ দেখায়
- Primary keyword অবশ্যই রাখো
- Hook লিখো — কেন ভিডিওটা দেখা উচিত
- Link দিও না এখানে

### Description Structure
```
🔹 HOOK (2-3 lines) — Primary keyword + value proposition
↓
🔹 SUMMARY (200-300 words) — Keyword-rich content description
↓
🔹 TIMESTAMPS — Chapter markers (0:00 format)
↓
🔹 CTA — Subscribe, Like, Comment
↓
🔹 SOCIAL LINKS — All your platform links
↓
🔹 KEYWORD FOOTER — Natural sentences with keywords
↓
🔹 HASHTAGS — 3-5 relevant hashtags
```

### Keyword Density
- Target: **১-৩%**
- ০.৫%-এর কম = YouTube বুঝবে না content কী নিয়ে
- ৫%-এর বেশি = Keyword stuffing (penalty risk)
- Natural ভাবে লেখো, জোর করে ঢুকাও না

## 🏷️ Tags Best Practices

### Tag Strategy
1. **First tag** = Primary keyword (সবচেয়ে গুরুত্বপূর্ণ)
2. **Next 5-10** = Secondary keywords + variations
3. **Next 10-15** = Long-tail keywords
4. **Last 5-10** = Broad category + related topics

### Character Limit
- YouTube limit: **৫০০ characters**
- Ideal: ৪০০-৫০০ characters ব্যবহার করো
- ২০-৪০টা tags ideal

### Important Notes
- Tags এখন আগের চেয়ে কম important (YouTube title + description-কে বেশি priority দেয়)
- কিন্তু tags এখনও "misspelling correction" এবং "related video suggestions"-এ help করে
- Irrelevant tags দিলে YouTube penalty দিতে পারে

## #️⃣ Hashtag Best Practices

- Maximum ৩-৫টা hashtags
- ১৫টার বেশি দিলে YouTube **সব ignore** করে
- Description-এর শেষে বা একদম প্রথমে রাখো
- First ৩টা hashtag video title-এর উপরে দেখায়
- Mix: ১ broad + ২ niche + ১ trending

## 🖼️ Thumbnail Best Practices

- **Text**: ৪-৬ words max
- **Font**: Bold, sans-serif
- **Colors**: High contrast (Yellow + Black, Red + White)
- **Face**: Expressive face থাকলে CTR ৩০%+ বাড়ে
- **Resolution**: ১২৮০x৭২০ minimum
- **Mobile test**: ছোট screen-এ পড়া যাচ্ছে কিনা check করো

## 📊 Post-Upload Optimization

1. **First 48 hours** সবচেয়ে critical
2. সব social media-তে share করো
3. Community post দিয়ে promote করো
4. Comments-এ reply করো (engagement বাড়ে)
5. End screen + cards ব্যবহার করো
6. ৭ দিন পর analytics check করো:
   - CTR কম? → Thumbnail/Title change করো
   - Watch time কম? → Content structure improve করো
   - Low impressions? → SEO re-optimize করো

---

## 🔄 Re-Optimization Strategy

পুরোনো ভিডিও SEO update করার নিয়ম:
1. YouTube Studio → Analytics → Reach → Search terms
2. কোন keywords-এ rank করছে দেখো
3. যেসব keyword-এ rank করছে কিন্তু title-এ নেই — title-এ যোগ করো
4. Description update করো নতুন keywords দিয়ে
5. Tags update করো
6. **মনে রাখো**: Title change করলে temporarily ranking drop হতে পারে
